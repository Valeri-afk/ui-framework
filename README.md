# UI Framework

C++20 UI framework built on SDL3.

The repository contains the current framework source code and architecture documentation used during development.

## Development

The framework is developed in independent architectural phases.

Current development is in **Phase 2 — Layout (source-level complete)**.

For recovering the current development context, start with:

- [Architecture](docs/ARCHITECTURE.md)
- [Development Roadmap](docs/ROADMAP.md)
- [Framework Scope](docs/FRAMEWORK_SCOPE.md)
- [Development Instructions](docs/INSTRUCTIONS.md)
- [Phase 1 Final Decisions](docs/PHASE1_FINAL_DECISIONS.md)
- [Phase 2 Constraint Semantics](docs/PHASE2_CONSTRAINT_SEMANTICS.md)
- [Phase 2 Numerical Layout Cases](docs/PHASE2_NUMERICAL_LAYOUT_CASES.md)

The source code is the authoritative source of truth.

Phase 2 source-level implementation is complete. Build, compilation and runtime tests are intentionally deferred until the end of Phase 6 by project decision. Until then, architectural consistency and numerical semantics are validated through source inspection and documented reference cases.
