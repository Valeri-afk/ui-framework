# UI Framework

C++20 UI framework built on SDL3.

The repository contains the current framework source code and architecture documentation used during development.

## Development

The framework is developed in independent architectural phases.

Current development is in **Phase 5 — Component Development**.

For recovering the current development context, start with:

- [Development Roadmap](docs/ROADMAP.md)
- [Framework Scope](docs/FRAMEWORK_SCOPE.md)
- [Component Design Guide](docs/COMPONENT_DESIGN_GUIDE.md)
- [Phase 5 Component Catalog](docs/PHASE5_COMPONENT_CATALOG.md)
- [Phase 5 Final Checkpoint](docs/PHASE5_FINAL_CHECKPOINT.md)
- [Phase 6 Scope Candidates](docs/PHASE6_SCOPE_CANDIDATES.md)
- [Architecture](docs/ARCHITECTURE.md)
- [Development Instructions](docs/INSTRUCTIONS.md)

`ARCHITECTURE.md` is the large architecture document and is intentionally not rewritten automatically during component development.

The source code is the authoritative source of truth for current behavior.

Build, compilation and runtime tests are intentionally deferred until the end of Phase 6 by project decision. Until then, architectural consistency is validated through source inspection and documented design decisions.
